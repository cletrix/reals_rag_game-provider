# Documento de Exemplo

Este é um documento de exemplo para teste do sistema RAG.

## Sobre o Projeto

Este é um sistema RAG híbrido com interface web estilo ChatGPT.

## Funcionalidades

- Embeddings locais via Ollama (bge-m3)
- LLM via Ollama local (llama3.2)
- Interface web para consulta de documentos
- Histórico de conversas
